# Инструкция по установке логотипа приложения (иконки Android) 🎨

Чтобы поменять стандартный логотип робота Android на ваш собственный логотип на экране телефона (launcher icon), выполните следующие простые шаги:

---

## Шаг 1. Подготовьте файлы логотипа

Вам нужно сохранить ваши изображения логотипа в новую папку `assets` в корне проекта (мы её уже создали для вас).

Для наилучшего результата (современная адаптивная иконка в Android) подготовьте два файла в формате **PNG**:
1. **Задний фон иконки**: `assets/icon-background.png` (Размер: **512x512 px** или **1024x1024 px**). Это может быть просто сплошной цвет или узор.
2. **Передний логотип**: `assets/icon-foreground.png` (Размер: **512x512 px** или **1024x1024 px** с прозрачным фоном). Это ваша основная иконка/логотип.

> **Упрощенный вариант (если нет раздельных слоев):**
> Просто положите один файл `assets/icon-only.png` (Размер: **1024x1024 px**). Генератор сам попытается сделать из него иконку.

*(По желанию вы также можете добавить заставку `assets/splash.png` размера 2732x2732 px для экрана загрузки).*

---

## Шаг 2. Запустите генерацию иконок для Android

Когда вы положите ваши файлы в папку `assets/`, выполните команду в консоли:

```bash
npm run generate-assets
```

### Что делает эта команда?
Она автоматически запускает `@capacitor/assets`, который:
* Берет ваши изображения из `/assets`.
* Профессионально масштабирует их под все необходимые разрешения Android (`hdpi`, `mdpi`, `xhdpi`, `xxhdpi`, `xxxhdpi`).
* Генерирует адаптивные и круглые иконки (`ic_launcher.png`, `ic_launcher_round.png`, `ic_launcher_foreground.png`).
* Автоматически помещает их в нужные папки вашего Android-проекта (`android/app/src/main/res/`).

---

## Шаг 3. Соберите APK файл

После успешного выполнения генерации, запустите сборку приложения как обычно в вашем GitHub репозитории или на локальном компьютере:

```bash
# 1. Сборка веб-интерфейса
npm run build

# 2. Синхронизация файлов в Android проект
npx cap sync android

# 3. Сборка готового APK (через Gradle или в GitHub Actions/Android Studio)
cd android && ./gradlew assembleDebug
```

---

🎉 **Всё готово!** Новая иконка мгновенно заменит стандартного робота Android на домашнем экране и в меню приложений!
